# Amazon Product Data Analysis

## Objective

Analyze product data and customer reviews to extract insights and sentiment trends.

## Tools Used

* Python (pandas, matplotlib, TextBlob)
* Jupyter Notebook

## Key Insights

* Identified top-performing product categories
* Analyzed customer sentiment (positive, negative, neutral)
* Found relationship between ratings and reviews

## Conclusion

Customer sentiment aligns strongly with product ratings, helping businesses improve decision-making.
